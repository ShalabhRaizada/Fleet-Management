# Fleet-Management

Home of **Tickie** modules.

## Modules

- [`tricktrack/`](tricktrack/) — **Tricktrack**, the IT Asset Management (ITAM) module.
  Asset master, approved request catalog, configurable approval workflows, allocation
  and returns, software license compliance, cloud cost governance with mandatory
  FinOps tags, and a complete append-only audit trail.

  ```bash
  cd tricktrack && npm run seed && npm start   # Node.js >= 22.5, zero dependencies
  ```
