# Fleet-Management

Home of modules for **Tickie** — the Portfolio and Project Management System.

## Modules

- [`ticktrack/`](ticktrack/) — **Ticktrack**, the IT Asset Management (ITAM) module.
  Asset master, approved request catalog, configurable approval workflows, allocation
  and returns, software license compliance, cloud cost governance with mandatory
  FinOps tags, and a complete append-only audit trail.

  ```bash
  cd ticktrack && npm run seed && npm start   # Node.js >= 22.5, zero dependencies
  ```
